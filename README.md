# Snap Studio — releases

Este repositório público contém somente instaladores para Windows e metadados usados pelas atualizações do aplicativo. O código-fonte fica no repositório privado do projeto.

Baixe a versão mais recente na aba **Releases**. A primeira migração da versão portátil exige instalar o aplicativo uma vez; depois, consulte **Configurações → Atualizações** no Snap Studio.
